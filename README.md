# LEX Web

LEX Web is a polished, responsive marketing site for a landing-page and website creation service.

## Direction

The site uses a dark editorial visual system with a warm coral-red accent, cream surfaces, oversized typography, layered cards, and browser mockups. It is designed to demonstrate web-design capability through the site itself.

## Included

- Responsive homepage
- Landing page, business website, and custom project service sections
- Three fictional portfolio concepts
- Process section
- LEX Web Desk with three articles
- Enquiry form (opens the visitor's email app), WhatsApp and email, none printed as plain text
- SEO metadata and sitemap
- No public pricing

## Deployment

This is a static HTML/CSS/JavaScript site and can be deployed directly to Vercel with Framework Preset set to **Other**. Leave build, output, and install commands blank.

## Contact

The public site obfuscates the contact details while keeping the email and WhatsApp buttons functional.
